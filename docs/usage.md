# Network Route Tool 使用说明

Network Route Tool 面向同时连接内网和外网的双网卡环境：让内网网卡承载内网流量、外网网卡承载外网流量，从而不用来回切换网络即可同时访问内外网。本文介绍安装、配置和常见问题。

## 安装

### 运行环境

- 操作系统：Windows 或 macOS，中文或英文环境均可。
- 运行环境：需要安装 JRE 或 JDK，建议使用 Java 8 及以上版本。

### 安装与启动

1. 从项目的 Releases 页面下载最新版本的程序包并解压；如果当前仓库暂无发布包，可使用上游项目 NetworkRouteTool 的发布版本。
2. 如果下载到的是可执行程序，直接运行即可；如果下载到的是 jar 包，请确保本机已安装 JRE，然后启动：
   - Windows（管理员命令提示符）：`java -jar <程序包名>.jar`
   - macOS（终端）：`sudo java -jar <程序包名>.jar`
3. 修改系统路由需要管理员权限：
   - Windows：右键程序并选择“以管理员身份运行”。
   - macOS：建议在终端中使用 `sudo` 启动，以便程序执行 `route` 命令。
4. 程序启动后会自动加载网卡信息，并显示在结果区；如果信息不正确，可以点击“更新网卡信息”重新读取。切换网卡或网卡 IP 变化后，程序重新获得焦点或展开网卡下拉框时会自动刷新列表，刷新时会保留当前已选的网卡。

## 配置

### 1. 选择内外网网卡

主界面顶部有两个下拉框：

- **内网网卡**：连接内网（如公司内网、服务器网段）的网卡。
- **外网网卡**：连接互联网的网卡。

下拉框中会列出网卡的 ID、名称、IP、掩码和网关。请选择两张不同的网卡，并确认两张网卡都获取到了有效网关（不能是 `0.0.0.0`），否则程序无法执行。

### 2. 配置内网白名单

白名单用于指定需要继续走内网网卡的目标网段。

- 配置文件：`WhiteList.config`，位于程序的工作目录（即启动程序时所在的目录）。
- 格式：每行一条记录，IP 与子网掩码之间用空格分隔；多条记录用换行分隔；以 `#` 开头的行为注释。
- 保存后，配置文件会用注释分成“已删除的IP（注释状态）”和“正在使用的IP（非注释状态）”两个部分，打开文件即可区分；已删除的记录取消注释后可以重新启用。

示例（保存后的配置文件）：

```text
# 已删除的IP（注释状态，取消注释即可重新启用）
#172.16.0.0 255.255.0.0

# 正在使用的IP（非注释状态）
192.168.1.0 255.255.255.0
10.0.0.0 255.0.0.0
```

在界面的“内网白名单”文本框中编辑后，点击“保存白名单”写入配置文件；程序启动时会自动读取。不需要白名单时，保持为空即可。保存时，从列表中移除的旧记录会以 `#` 注释的形式保留在配置文件最前面的“已删除的IP”部分。

### 3. 执行路由

点击“执行路由”后，程序会：

1. 删除内网网卡的默认路由；
2. 为内网网段添加指向内网网关的路由；
3. 将默认路由指向外网网关；
4. 按白名单逐条添加指向内网网关的路由。

执行结果会显示在下方的文本区。点击“更新网卡信息”可以重新读取网卡和网关，刷新后仍会保持当前选择的网卡，并显示该网卡最新的 IP、掩码和网关。点击“获取最新版本”会打开上游项目 NetworkRouteTool 的发布页面。

### 4. 日志

程序会在工作目录的 `logs` 文件夹下写入日志：`info.log` 记录运行信息，`error.log` 记录错误信息。排查问题时可以先查看这两个文件。

## 常见问题

**启动时提示 “No JVM could be found on your system...” 或提示 `EXE4j_JAVA_HOME`？**
本机没有安装 JRE/JDK。安装 Java 8 或更高版本后重新启动程序。

**执行时提示 “请求的操作需要提升” 或 “The requested operation requires elevation”？**
修改路由需要管理员权限。Windows 请以管理员身份运行程序；macOS 请在终端使用 `sudo` 启动。

**网卡网关显示为 `0.0.0.0`？**
通常是手动配置 IP 时没有填写默认网关，或者 DHCP 刚获取到 IP、网关尚未就绪。请为网卡补全默认网关；如果是刚插上网线，等待 15 秒到 1 分钟后点击“更新网卡信息”。

**提示“当前只检测到有一张网卡”或“内外网为同一张网卡”？**
请确认两张网卡都已连接并启用，且在内网、外网下拉框中选择了不同的网卡。

**提示白名单格式错误？**
每条记录必须是“IP 子网掩码”，中间用一个空格分隔，IP 和掩码的每一段都要在 0~255 之间；多条记录用换行分隔。例如：`192.168.1.0 255.255.255.0`。

**找不到 `WhiteList.config`？**
程序会在工作目录中查找该文件。在该目录新建文件并按上面的格式填写即可；不需要白名单时可以忽略。

**执行后如何恢复原来的路由？**
拔下并重新插上对应网卡的网线即可恢复；重启系统可以完全恢复初始路由。可能残留的少量路由不会影响正常使用。

**执行后仍无法访问内网或外网？**
请检查内外网网卡是否选择正确、网关是否有效、白名单是否覆盖了需要访问的内网网段，同时查看 `logs/error.log` 中的错误信息。
